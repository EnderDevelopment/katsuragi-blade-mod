# Kyokusui Mod

Kyokusui Mod is a Minecraft mod that adds the Kyokusui sword to the game. This mod is designed for Minecraft version 1.20.1 and requires the Fabric Loader to be installed.

## Installation

1. Install Fabric Loader for Minecraft 1.20.1.
2. Download the Kyokusui Mod jar file from the GitHub repository.
3. Place the downloaded jar file in the mods folder of your Minecraft installation directory.

## Usage

1. Launch Minecraft with the Fabric Loader installed.
2. The Kyokusui sword will be available in the game.
